# 工作日誌產生器

左邊填寫、右邊即時排版、一鍵複製。純前端靜態網頁，無後端、資料不離開瀏覽器。

線上版：https://mktcycy.github.io/worklog-tool/

## 功能

- 日期自動帶今天（可改），標題列與「Trista 代班業務學習」為固定文字
- **簡體自動轉繁體**：客戶服務、例行工作各欄、分析異常資料、額外學習
- **不轉換**：網站資料抓取與檢視的「主要獲利 / 主因」（依需求保留原文）
- 例行工作每項標題一律顯示，沒填內容就只出標題
- ACC入帳檢查：入款無誤 ／ 入款異常已回報（選後出現說明欄）
- 負損益可新增多組，自動編號為 負損益1、負損益2…；選「無」則整段不輸出
- 檢視案件單：完成才輸出該行
- 每個多行項目可勾「內容換行」決定要同行還是條列

## 簡繁轉換怎麼做的

沒有呼叫任何外部 API，字典內建在 `dict.js`。

來源是 OpenCC 的 `s2tw` 字典（STCharacters + STPhrases + TWVariants），
並把「逐字轉換結果本來就正確」的冗餘片語剔除：49,051 條 → 9,825 條，
檔案壓到 146 KB，轉換結果與 OpenCC 完全一致（19 組實例比對 0 差異）。

另加一條台灣用字修正：`賬` → `帳`（記帳／帳戶）。

轉換採最長片語優先比對，所以能正確處理歧義字：
頭髮、乾淨、後面、裡面、什麼、發現、製造、麵條、皇后、幹部。
